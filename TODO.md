# План Velocity

[← Обзор проекта](https://github.com/SayGGGo/Velocity/blob/main/)

Задачи расположены по приоритету. Это направления развития, а не обещания сроков.

## P0 · Надёжность и безопасность

- [ ] Сделать вход, восстановление доступа и управление сессиями понятнее.
- [ ] Улучшить прозрачность оплаты и состояния покупок.
- [ ] Развивать защиту аккаунтов и пользовательских данных.

## P1 · Удобное обучение

- [ ] Сократить путь от регистрации до первого полезного результата.
- [ ] Улучшить сценарии подготовки к ЕГЭ, ОГЭ, сессии и учебным проектам.
- [ ] Улучшить работу на телефонах и доступность интерфейса.
- [ ] Ускорить загрузку и сделать длительные AI-ответы удобнее для чтения.

## P2 · Развитие продукта

- [ ] Улучшать рекомендации следующего учебного шага.
- [ ] Развивать инструменты по обратной связи пользователей.
- [ ] Проработать предложения для образовательных команд.

## P3 · VLTY SHOP

- [ ] Подготовить образцы и уточнить характеристики товаров.
- [ ] Опубликовать условия доставки, оплаты и возврата.
- [ ] Открыть заказы после подготовки магазина.

Мерч пока недоступен для заказа.
